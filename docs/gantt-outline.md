# 간트 외곽선 곡률 규칙

예정·실제 막대가 맞닿으면 하나의 SVG 외곽선으로 그린다. 기본 모서리 반경은 각 막대의 CSS 값을 따르며, 짧은 변에서는 인접 변 길이의 절반으로 제한한다.

| 실제 날짜 | 외곽선 처리 |
| --- | --- |
| 없음 | 예정 막대의 모서리 반경 적용 |
| 시작일만 | 실제 막대의 오른쪽 열린 곡선이 예정 종료 쪽으로 합류한다. 종료 위치가 같으면 예정 오른쪽 아래 모서리의 반경을 유지한다. |
| 종료일만 | 실제 막대의 왼쪽 열린 곡선이 예정 시작 쪽으로 합류한다. 시작 위치가 같으면 예정 왼쪽 아래 모서리의 반경을 유지한다. |
| 둘 다 | 두 기간을 합친 외곽선의 볼록·오목 모서리를 모두 둥글게 처리한다. |

| 연결선 위치 | 외곽선 처리 |
| --- | --- |
| 연결 없음 | 기본 반경 유지 |
| 왼쪽 끝면 | 연결된 막대의 왼쪽 위·아래 반경을 0으로 설정 |
| 오른쪽 끝면 | 연결된 막대의 오른쪽 위·아래 반경을 0으로 설정 |
| 위·아래 면 | 모서리를 피해 연결하고 기존 반경 유지 |

끝면 연결은 선행 막대의 오른쪽과 후행 예정 막대의 왼쪽에 적용한다. 실제 종료일이 없으면 선행 연결은 예정 막대에서 출발한다. 실제 종료일이 있으면 더 늦은 종료일의 막대를 사용하고, 두 종료일이 같으면 후행 작업이 있는 방향의 바깥쪽 막대를 사용한다.

열린 곡선과 직선의 접점은 곡선 끝점의 접선 방향으로 반경을 계산한다. 곡선이라는 이유만으로 반경을 제거하지 않는다. 서로 떨어진 기간은 별도 외곽선을 유지하고, 열린 쪽의 추정 날짜는 저장하지 않는다.

검증: `tests/test_unified_task.cjs`, `tests/test_gantt_dates.cjs`, `tests/test_dependency_rendering.cjs`.
